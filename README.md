# Simple Interest Calculator

## Project Name: Simple Interest Calculator

A lightweight Bash-based tool to calculate **simple interest** from user-provided inputs.

## Description

This project provides a command-line calculator that computes simple interest using the formula:

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Features

- Takes user input for **Principal**, **Rate of Interest**, and **Time Period**
- Computes and displays the **Simple Interest**
- Lightweight Bash script — no dependencies required

## Usage

```bash
bash simple-interest.sh
```

Follow the prompts to enter:
1. Principal amount
2. Annual rate of interest (%)
3. Time period (in years)

## Example

```
Enter the principal: 1000
Enter the rate of interest: 5
Enter the time period: 3
The simple interest is: 150
```
